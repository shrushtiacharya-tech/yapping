# **App Name**: AnonConnect

## Core Features:

- Anonymous Video Chat: Initiate one-on-one video chats with random users.
- Text Chat: Allow users to exchange text messages during video calls.
- Interest-Based Matching: Match users based on shared interests using AI powered tool, entered via tags, to enhance connection relevance. A vector database of user profiles is updated whenever a user adds a new tag to their profile
- Chat History (Optional): Allow users to review a log of past chat sessions.
- Report User: Allow users to report inappropriate behavior.
- Banned User List: Maintain a record of banned users in Firestore and prevent them from accessing the platform.

## Style Guidelines:

- Primary color: Deep Indigo (#663399) to evoke a sense of mystery and anonymity.
- Background color: Light gray (#F0F0F0) to ensure content stands out against a neutral backdrop.
- Accent color: Teal (#008080) for interactive elements, providing a subtle but engaging contrast.
- Body and headline font: 'Inter' for a modern, machined feel.
- Simple, outline-style icons for navigation and actions.
- Clean and minimal layout with a focus on video stream and chat window.
- Smooth transitions and subtle animations for a seamless user experience.
